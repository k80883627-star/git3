Git Branch Management

Aim

To create a Git repository and develop features using multiple branches and merge them into the main branch.

Features

  • Home Page
  • Login Page
  • Contact Page

Git Commands

1. Initialize Repository

git init

2. Create Main Branch

git branch -M main

3. Create Login Feature Branch

git switch -c login-feature

4. Add and Commit Changes

git add .
git commit -m "Added login feature"

5. Switch to Main Branch

git switch main

6. Merge Login Feature

git merge login-feature

7. Create Contact Feature Branch

git switch -c contact-feature

8. Commit Contact Feature

git add .
git commit -m "Added contact feature"

9. Merge Contact Feature

git switch main
git merge contact-feature

Procedure

  1. Create a Git repository.
  2. Create separate branches for different features.
  3. Develop and commit changes in each branch.
  4. Switch to the main branch.
  5. Merge the feature branches into the main branch.
  6. Verify the changes using git log.

Result

Thus, a Git repository was created, features were developed using multiple branches, and the branches were merged into the main branch successfully.
